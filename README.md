Aurora - Plataforma para Gestão de Pessoas

Landing page institucional da *Aurora*, uma plataforma de inteligência artificial aplicada ao RH para ajudar líderes a tomar decisões estratégicas sobre promoção, retenção e desenvolvimento de talentos.

URL: https://aurora-chi-neon.vercel.app

## Sobre o Projeto

A Aurora conecta inteligência de dados e gestão humana, oferecendo:

- **People Analytics** - Dashboards interativos de indicadores de pessoas.
- **Predição de Rotatividade** - Antecipe riscos de desligamento com IA.
- **Performance Insights** - Identifique talentos e oportunidades de crescimento.
- **Recomendações Inteligentes** - Apoio guiado por IA na tomada de decisões de RH.

Este projeto foi desenvolvido como uma landing page para apresentar a solução e captar leads por meio de um formulário de demonstração.

---

## Funcionalidades

- Layout responsivo (mobile, tablet e desktop)
- Formulário de captação de lead com validação
- Seção de FAQ interativa (accordion)
- Navegação suave entre seções
- Mensagem de sucesso após envio do formulário
- Acessibilidade: HTML semântico, ARIA, foco visível, labels e alt em imagens

## Responsividade

O site foi desenvolvido com abordagem **mobile-first** e se adapta a:

- Celulares (320px+)
- Tablets (768px+)
- Desktops (992px+)

---

## Acessibilidade

O projeto implementa boas práticas de acessibilidade:

- HTML semântico (`<nav>`, `<section>`, `<footer>`)
- Hierarquia de títulos (`<h1>`, a `<h6>`)
- Imagens com `alt` descritivo
- Labels associados aos campos do formulário
- Atributos ARIA no menu e FAQ
- Foco visível para navegação por teclado
- Mensagem de sucesso com `role=alert`
